# 03 — Failure-Driven Debugging\n\n```md\nDebug this issue without shotgun fixes.\n\n## Symptom\n<exact error / failing behavior>\n\n## Mandatory cycle\nFor each attempt, provide:\n- Hypothesis\n- Prediction: \"If correct, we will observe ...\"\n- Falsifier\n- Single diagnostic or fix\n- Observed result\n\n## Hard gates\n- No fix without a prior hypothesis.\n- After 2 failed hypotheses for same symptom: reset reasoning and restate root symptom.\n- Ask at most one question per turn if evidence is missing.\n\n## Output\nReturn: root cause confidence, fix, and verification proof.\n```\n
