# 06 — Test-First Fix

```md
Fix this bug with test-first discipline.

## Bug
<description>

## Process
1) Write/identify a failing test that reproduces bug
2) Show failure output
3) Implement minimal fix
4) Re-run targeted + related tests
5) Explain why fix is sufficient

## Rules
- No fix before reproducible failing test (unless impossible; explain why)
- Prefer smallest behavior-preserving patch

## Completion gate
Must show failing -> passing proof chain.
```
