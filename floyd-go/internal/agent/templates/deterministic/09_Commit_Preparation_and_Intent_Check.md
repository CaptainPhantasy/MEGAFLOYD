# 09 — Commit Preparation + Intent Check

```md
Prepare a commit candidate but do not commit until I confirm.

## Required process
1) Summarize changed files by category
2) Flag risky/unrelated changes
3) Propose commit scope options (A/B/C)
4) Ask explicit YES/NO confirmation

## Output
- What will be committed
- What will be excluded
- Proposed commit message (why-focused)

## Gate
No commit action without explicit user confirmation.
```
