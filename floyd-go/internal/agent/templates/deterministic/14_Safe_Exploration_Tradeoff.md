# 14 — Safe Exploration + Tradeoff Analysis

```md
Explore options without pretending certainty.

## Problem
<statement>

## Generate exactly 3 options
For each option provide:
- Benefits
- Risks
- Cost (implementation + ops)
- Time to deliver
- Failure mode

## Recommendation format
- Preferred option
- Why now
- What would change recommendation

## Rule
Do not recommend without explicit tradeoff justification.
```
