# 15 — Handoff + Continuity Pack

```md
Prepare a zero-loss handoff for the next session.

## Required sections
1) Objective in progress
2) Completed work with evidence
3) Exact current state (branch/files/tests)
4) Open risks/blockers
5) Next 3 actions (ordered)
6) Copy-paste restart prompt

## Restart prompt template
"Resume task: <objective>. Current state: <state>. Start with action #1: <action>."

## Gate
Handoff is invalid if next action is ambiguous.
```
