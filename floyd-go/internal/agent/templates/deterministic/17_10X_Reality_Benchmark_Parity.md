**Value Class:** 10X Multiplier (transfers benchmark quality into real tasks)

```md
Use this to force benchmark-grade rigor on messy real-world tasks.

## Task
<real task>

## Parity controls
- Start from clean objective statement (1 sentence)
- Limit active scope to max 3 subgoals at once
- Require deterministic proof after each subgoal
- No speculative prose between actions

## Deterministic loop
1) State next smallest action
2) Execute action
3) Provide output evidence
4) Evaluate against acceptance criterion
5) Continue or stop with blocker

## Output format
- Goal board: G1/G2/G3
- Action log: step -> evidence -> verdict
- Drift check: "Any requested section not addressed?"
- Final parity score: met/not met with reasons

## Hard gate
Any missing requested section => parity failed => status INCOMPLETE.
```
