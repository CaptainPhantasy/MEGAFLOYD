# Btw — Quick Side Question

Ask a small question about the current work without derailing the task in progress. The answer comes from conversation context already in this session — no new investigation, no tool calls, no follow-up questions.

## Usage
```
/btw <QUESTION>
```

## Procedure
1. Answer from what is already in this session's context (conversation, files already read, commands already run).
2. One concise reply. If the answer is not already in context, say so in one sentence and offer to investigate after the current task — do not investigate now.
3. Resume the interrupted task exactly where it left off. Do not restate the plan or ask what to do next.

## Rules
- No tool calls. This skill exists to be cheap.
- Never expands scope: a btw answer never changes the current task's plan.
